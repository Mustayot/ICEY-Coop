玩家使用 GitHub Releases 附件 ZIP；GitHub 自动提供的 Source code ZIP 为源码。仓库不收录 artifacts 输出、游戏本体或个人存档。installer/payload 是完整离线安装器的受检输入，暂保留已冻结的模组/加载器二进制，便于不依赖私人开发环境生成同一构建的可用安装器。

.github/workflows/release.yml 在 main 更新 manifest 或发布工作流时运行，也可手动触发。它验证冻结载荷、生成完整 ZIP/SHA256，再按 manifest.version 创建发布；同标签已存在时保留原附件。该流程不编译游戏桥接、不运行游戏，不能代替本机游戏回归。云端 ZIP 元数据可导致整体 SHA 与本地 ZIP 不同，应以各自随包 SHA 为准；载荷仍逐项受 manifest 约束。
